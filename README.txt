MAINCRAFTS TECHNOLOGY — TASK 2
================================

Included files:
- index.html       Home page
- about.html       About page
- contact.html     Contact page with JavaScript validation
- css/style.css    Shared responsive design
- js/script.js     Mobile menu, footer year, and form validation

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Test the Home / About / Contact links and resize the browser to check mobile responsiveness.

IMPORTANT
The contact form currently validates in the browser only. It does not send email or save submissions.
To receive messages, connect it to a backend or a form service.
The Google Fonts import requires internet access; system fallback fonts are provided.

Customize:
- Change contact email and website details in contact.html.
- Edit colors near the top of css/style.css in the :root section.
- Update service and about text directly in the HTML files.
